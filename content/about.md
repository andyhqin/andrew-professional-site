Hi, I'm Andrew! I'm a cloud software engineer at Intel, and I've been building
software for about 12 years.

I'm a nerd at heart. I've always wanted to know how things work, and the best
way I've found to learn is to take something apart and put it back together.
I built my own PC from scratch, I run a homelab, and I've spent plenty of
evenings cracking open laptops to upgrade parts (back when RAM didn't cost a
fortune). I bring the same curiosity to software: I read the source, trace the
request, and keep poking until the system makes sense.

## What I work on

I build full-stack apps and the cloud infrastructure that runs them, from the
React frontend all the way down to the database, plus the pipeline that ships
it all. Here's what's in my toolbox:

- **Languages:** JavaScript, TypeScript, and Python
- **Frontend:** React
- **Backend:** Node.js, npm, and serverless APIs
- **AWS:** API Gateway, Lambda, RDS, EC2, ECR, Secrets Manager, and plenty more
- **Infrastructure:** Terraform, Docker, and Kubernetes
- **Delivery:** CI/CD pipelines with GitHub Actions
- **Data:** Postgres and MongoDB
- **Testing:** unit, functional, and end-to-end suites with pytest, Jest,
  Mocha, and Selenium

Lately I've been playing around with newer web app tech on the side, just to
see what it can do. (This site is one of those experiments.)

## How I like to work

I'm a big fan of clean, easy-to-read code. Code gets read way more often than
it gets written, so I try to leave things that the next person can pick up
quickly, even when that next person is me six months from now.

I also think code isn't really done until it's tested. I've built test suites
at every level, from quick unit tests to full end-to-end browser tests, so
changes can ship without anyone holding their breath.

And I love a good puzzle. A tricky bug, a slow pipeline, or a system nobody
quite understands? That's my kind of fun.

## Outside work

Away from the keyboard, I'm still drawn to anything that takes some creative
problem solving. I rock climb, I fix things around the house, and you can
find me at [Puzzled Pint](https://puzzledpint.org), a monthly puzzle hunt.

I'm also really into partner dancing: salsa, Brazilian zouk, and Argentine
tango. Turns out it has a lot in common with good engineering. It takes
practice, clear communication, and paying close attention to your partner.
